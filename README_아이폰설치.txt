숫자 탐험대 — iPhone PWA 버전

[아이폰에서 앱처럼 쓰는 방법]
1. 이 폴더의 파일들을 HTTPS 웹사이트에 올립니다.
   - GitHub Pages, Netlify, Vercel 같은 무료 호스팅을 사용할 수 있습니다.
2. 아이폰에서 반드시 Safari로 해당 주소를 엽니다.
3. Safari 하단/상단의 공유 버튼을 누릅니다.
4. '홈 화면에 추가'를 선택합니다.
5. 홈 화면에 생긴 '숫자탐험대' 아이콘을 누르면 앱처럼 전체화면으로 실행됩니다.
6. 한 번 온라인에서 실행한 뒤에는 주요 화면이 오프라인에서도 열리도록 캐시됩니다.

[중요]
- 아이폰에서 로컬 HTML 파일을 '파일' 앱으로 직접 여는 방식은 PWA 설치와 서비스워커가 정상 작동하지 않습니다.
- PWA 기능은 HTTPS 주소에서 열어야 합니다.
- 음성인식은 iOS/Safari 버전에 따라 지원 상태가 달라질 수 있습니다.
  이 경우 앱이 자동으로 음성 버튼을 숨기거나 비활성화하고, 모든 문제를 터치로 풀 수 있습니다.

[포함 기능]
- 공룡 / 자동차 테마
- 1~10 수량 세기
- 숫자 ↔ 수량 연결
- 8·9 집중 연습
- 수량 비교
- 숫자길
- 하나 더(+1)
- 10칸 수틀
- 부모용 학습기록
- 적응형 출제
- 브라우저 로컬 저장
- PWA 홈화면 설치
- 오프라인 캐시
